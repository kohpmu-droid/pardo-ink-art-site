# Pardo Ink Art — אתר הבית

אתר בית (עמוד נחיתה) לקליניקת הבוטיק **Pardo Ink Art** — קעקועים אמנותיים, איפור קבוע, קעקועים רפואיים, הסרת לייזר והדרכות.

## מבנה
- `index.html` — כל האתר (עמוד יחיד, RTL, Tailwind via CDN)
- `IMG_2402.jpg` — הלוגו המוצג כרגע
- `logo.png` — הלוגו השקוף (לשימוש עתידי)

## פרסום אוטומטי של מאמרים

`tools/publish_from_queue.py` מפרסם מאמר אחד מהתור (`content/meta` + `content/bodies`)
ומוסיף לו כרטיסייה ב-`articles.html`.

**התזמון אקראי.** ה-workflow (`.github/workflows/publish-article.yml`) מתעורר כל שעתיים,
והסקריפט מחליט אם עברו מספיק שעות — מרווח אקראי בין 12 ל-24 שנבחר מחדש אחרי כל פרסום
ונשמר ב-`content/.publish_state.json`. אם קובץ המצב חסר או פגום — מפרסם, כדי שהתור
לא ייתקע בשקט.

**מונה המאמרים** בכותרת כל קטגוריה נספר מחדש בכל ריצה (`refresh_counts`) ולא מוגדל,
כך שריצה שנכשלה מתוקנת בריצה הבאה. עד 19.8.2026 המונה היה תקוע על 12/14 במקום 19/21
כי ה-regex הקודם חיפש אותו במקום הלא נכון ונכשל בשקט.

**להרצה ידנית:** Actions ← Publish queued article ← Run workflow.


## עמודי מחירון

ארבעה עמודים, מקושרים זה לזה ומופיעים בתפריט תחת "מחירון":

| עמוד | תוכן |
|------|------|
| `piercing-prices.html` | מחירון פירסינג מלא (מקור: המחירון הרשמי מ-28.7.2026) |
| `tattoo-prices.html` | קעקועים קטנים; קעקוע אמנותי בתמחור אישי אחרי ייעוץ |
| `laser-prices.html` | הסרת קעקוע בלייזר וסדרות, הסרת איפור קבוע, טיפולי פנים |
| `services-prices.html` | איפור קבוע, קעקוע רפואי להסוואת צלקות, פילינג קרבון |

**כשמעדכנים מחיר — לעדכן גם את `src/knowledge.js` בריפו `pardo-whatsapp-agent`.**
הסוכן בוואטסאפ מקריא מחירים מבסיס הידע שלו, לא מהאתר; רק רשימת המאמרים נמשכת מהאתר
בזמן ריצה. מחיר שיתעדכן רק כאן ייצור פער בין מה שכתוב באתר למה שהסוכן אומר.


## גלריות ותמונות אוטומטיות מהדרייב

שלוש גלריות, כל אחת עם עמוד משלה:

| עמוד | תיקיית תמונות | קידומת | תיקייה בדרייב |
|------|----------------|---------|----------------|
| `gallery.html` | `images/gallery` | `gNN` | תמונות לאתר / **קעקועים** |
| `piercing.html` | `images/piercing` | `pNN` | תמונות לאתר / **פירסינג** |
| `laser.html` | `images/laser` | `lNN` | תמונות לאתר / **הסרה בלייזר** |

תיקיית האב בדרייב: <https://drive.google.com/drive/folders/1nq8uYmXYuUkPwv7ysY6avsN2alTzVcrO>
(היא יושבת בתוך "לקוחות פירסינג" מסיבות היסטוריות). מזהי שלוש התיקיות מקודדים
בראש `tools/sync_gallery_images.py` — **אם מוחקים או מעבירים תיקייה בדרייב, לעדכן שם.**

### איך זה עובד

`.github/workflows/sync-gallery.yml` רץ **כל יום ראשון ב-06:00** (וגם ידנית:
Actions ← Sync gallery images from Drive ← Run workflow). הסקריפט
`tools/sync_gallery_images.py`:

1. סורק את שלוש התיקיות ומדלג על כל מה שכבר פורסם
2. מוריד, מיישר לפי EXIF, מקטין ל-1400px ודוחס ל-JPEG (‏~70–100KB במקום 8MB)
3. שומר כ-`gNN/pNN/lNN.jpg` וממקם את החדשות **בראש** הגלריה
4. שם הקובץ בדרייב הופך ל-alt של התמונה — לכן כדאי שמות תיאוריים בעברית

**המעקב לפי מזהה הקובץ ב-Drive**, בקובץ `images/.gallery_state.json`. לכן: שינוי שם
בדרייב לא יגרום להעלאה כפולה, ומחיקה מהדרייב לא מוחקת מהאתר. כדי להסיר תמונה מהאתר
צריך למחוק אותה מ-`images/` וגם מרשימת התמונות בעמוד.

**קבצים שיושבים ישירות ב"תמונות לאתר" ולא בתת-תיקייה — מתעלמים מהם.** ה-30 שכבר שם
פורסמו בעבר ידנית; להעביר אותם לתת-תיקייה יגרום לפרסום כפול.

### רשימת התמונות בעמוד

בכל עמוד גלריה יש בלוק שהסקריפט מנהל:

```js
/* AUTO-GALLERY-START */
var images = [ ["p25", "פירסינג טבור"], ["p24", ""] ];
/* AUTO-GALLERY-END */
```

הסדר בתוך המערך הוא סדר התצוגה — אפשר לערוך ידנית (למשל להעלות תמונה מוצלחת לראש),
הסקריפט שומר על מה שכתוב שם ורק מוסיף בהתחלה. `alt` ריק נופל חזרה לטקסט ברירת המחדל
של העמוד.

### הרשאות גוגל

הסקריפט ניגש לדרייב עם OAuth refresh token בהיקף `drive.readonly` (קריאה בלבד),
דרך אותו OAuth client של פרויקט ה-Google Cloud שמשמש את `GBP_*` ב-`pardo-auto-publisher`.
שלושה סודות ב-GitHub: `GDRIVE_CLIENT_ID`, `GDRIVE_CLIENT_SECRET`, `GDRIVE_REFRESH_TOKEN`.

להפקת טוקן חדש (למשל אם נשלל): `python tools/gdrive_auth.py <CLIENT_ID> <CLIENT_SECRET>`.
דורש ש-`http://localhost:8080/` יהיה redirect URI מאושר אצל אותו client, ושה-scope
של דרייב יאושר במסך ההסכמה. אם ה-app במצב Testing — הטוקן פג אחרי 7 ימים, ואז צריך
להעביר אותו ל-Production (או להפיק מחדש כל שבוע).
